# Hey, I'm Bruno

I turn discontinued hardware into something useful.

Right now I'm hacking a **Logitech EasyCall Speakerphone** from 2008 into a fully functional SIP desk phone — running on a Raspberry Pi 5 with Asterisk PBX, baresip, and a Python daemon that listens to the physical buttons via reverse-engineered USB HID.

### Projects

- [easycall](https://github.com/brunoclausen/easycall) — Logitech EasyCall som SIP-bordtelefon (dansk)
- [easycall-en](https://github.com/brunoclausen/easycall-en) — Logitech EasyCall as a SIP desk phone (English)
